Download for macOS

Beacon is for macOS 14+.

brew install --cask avivhdr/tap/beacon

The three tabs

Unread

Comments, replies, and mentions that need you. Opening one marks it read.

To review

Categories for what is waiting. Hide one pull request, or a whole repository. CI and stale state stay on the row.

Mine

Your own open pull requests, in layers. Repositories fold and stay folded. This tab stays out of the menu bar.

Setup

  1. Install Beacon

    Open the disk image and drag Beacon to Applications, or use the Homebrew command above.

  2. Sign in

    Run gh auth login. If an organization uses single sign-on, authorize the token for that organization.

  3. Look at the menu bar

    Two counts appear: unread, and reviews. Your own pull requests are on the Mine tab.

Review filters live in the panel. The config file is ~/.config/beacon/config.json. Beacon reads it again on every poll.

Privacy

Beacon reads the token from gh. The token stays on your Mac. Beacon sends it only to api.github.com. There is no analytics, and there is no other server.
